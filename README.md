# Book Store API 

A comprehensive Backend RESTful API built with **Node.js**, **Express.js**, and **MongoDB**. It provides robust features for an e-commerce bookstore platform.

---

##  Features
- **User Authentication & Authorization**: Secure sign-up, login, and JWT-based authentication.
- **Password Reset System**: Forgot and reset password functionality via Nodemailer and secure token verification.
- **Book Management**: Complete CRUD operations for books and authors.
- **Image Uploads**: File uploading using Multer middleware.
- **Input Validation**: Request body validation using Joi and `joi-password-complexity`.

---

##  Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB & Mongoose
- **Authentication**: JSON Web Tokens (JWT), Bcrypt.js
- **Utilities**: Nodemailer, Multer, Joi
